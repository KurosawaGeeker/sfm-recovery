# SFM Recovery

SFM 的游戏行为研究与恢复工程，当前集中于“家里—街区”的基本游玩流程。

## 当前范围

- 家里与街区之间的移动、任务和返家结算。
- 购物、装备、身体参数与保存读取。
- NPC 巡逻、交互、发现及失败后的返家流程。

工程仍在开发和验证中，尚未完成完整游戏的恢复。这个公开仓库目前处于初始化阶段，首个提交提供项目说明、许可和发布文件规则。

## 发布内容

公开内容将逐项整理。游戏安装文件、提取资源、Unity 编辑器、个人存档、凭据和本机运行日志保留在本地工作环境。

本仓库采用 MIT 许可，许可范围为本仓库中由项目贡献者提供的原创内容。第三方游戏及资源的权利归各自权利人所有。
