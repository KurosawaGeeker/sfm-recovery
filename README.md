# SFM Recovery

## 为什么做这个项目

我不认为 AI 逆向会毁掉独立游戏。恰恰相反，正因为一款游戏足够优秀，才有人愿意花时间和钱继续研究它——光是逆向 SFM，我就已经花了数百美元，够买十几份原作。|

成人游戏里，有太多让人意难平的作品：概念惊艳、交互出色，最后却太监了（比如凉花酱，太多数不清）；作者靠赞助就能养活，无限跳票，玩家的期待慢慢耗尽（比如《棘罪修女》；还有成功的作品，因为作者转向全年龄，再也等不到续作比如《塞雷卡2》。作者当然有权选择自己的方向，但玩家也希望这些好点子能继续生长。

偏偏 IL2CPP 的编译形式又极大地抬高了 Mod 开发的门槛。想自己补完遗憾，也往往无从下手。

所以，我想用 SFM 做一次示范：别把所有对黄油的期待都押在下一次更新、下一部续作上。

有了 AI，普通玩家也有机会研究游戏如何运作，恢复它的代码，在已有的优秀系统上构建自己喜欢的玩法。

与其无限期等待下一个 SFM，不如动手创造自己想玩的那个版本。

我愿意为优秀的原作付费，也希望玩家拥有更多参与创造的空间。成人游戏应当是开放的，自由的，平等的——让好创意获得支持，也让任何热爱它的人有机会把它继续做下去。

我也希望以后的成人游戏作者，不要再用 il2cpp，因为它挡不住盗版，有人做 mod，游戏生态才会更好，才会有更多人去购买原作，比如上古卷轴5。

## 项目说明

用 Codex、REA 和实际 Unity Player，逐步恢复 SFM 的游戏代码与行为。目前集中在“家 → 街区 → 回家”的主要流程。

这个仓库公开 **Unity C# 源码快照和逆向过程记录**，不包含原游戏、静态资源或可执行构建。它是仍在验证中的研究工程，不是完整还原版，也不能仅凭本仓库直接构建可玩的游戏。

## 谁做了什么

**实现主要由 AI 完成，用户基本没有逐函数指导或提供实现补丁。** 用户主要负责给目标、授权环境操作、试玩和指出问题。比如要求停止无目的扩大资源，改为先完成家—街区闭环；坚持任务结算、NPC 发现失败、购买换装、姿势、捏脸捏身材都要实际走通；指出白底白字和声音反馈不对。

因此，这可以描述为“很少人工编码介入的 AI 主导逆向”，但不是无人干预：用户的范围控制和试玩反馈对方向很重要。提示词文档保留了这些关键介入，而不是只挑“继续”来展示。

## 已达到的范围

本地已有独立 Unity Player，并分别留存了移动/跑步/松开停止、购物装备、外形调整、技能姿势、任务奖励及 NPC 失败返家的运行证据。部分证据来自不同版本之间经过代码一致性检查的继承，不能当作最新版本一次完整跑通全部系统。

最近一次用户试玩认可了家—街区基本系统，同时报告了 UI 对比度、角色问号、NPC 头顶发现反馈和音效/音乐问题。最新 `home-street-feedback-v3` 已供试玩，自动六面板回归仍未通过；人物偏暗和街区光照切换也在继续核查。**完整流程、动画、渲染与声音全面对齐仍未验收。** 具体范围见 [当前状态](docs/REVERSE_ENGINEERING.zh-CN.md#当前状态与剩余工作)。
